Connecting the drone

The toy Wi-Fi drone streams video; AeroScan reads the latest frame and drops stale ones.

  1. Power the drone and join its Wi-Fi network from this PC.
  2. In Exterior, press Drone feed and connect to rtsp://192.168.1.1:7070/webcam.
  3. If RTSP does not open, mirror the phone running the RC UFO app with scrcpy, then use Screen mirror with the window region left,top,width,height.
  4. Select the section the drone is inspecting (keys 1–5, N for next). New defects are tagged to it.
  5. No drone? Upload a test image or a short video. Videos play at real-time speed.
